# 上线前检查清单

本文档用于当前 `backend` 项目正式上线前的最终核对。

## 1. 基础设施

- MySQL 已启动，目标库已创建，账号具备建表 / 迁移权限
- Redis 已启动，应用机器到 Redis 网络可达
- SMTP 邮件服务可用，已验证能正常发信

## 2. 必填环境变量

- `DB_URL`
- `DB_USERNAME`
- `DB_PASSWORD`
- `JWT_SECRET`
- `MAIL_SMTP_HOST`
- `MAIL_ACCOUNT`
- `MAIL_AUTH_CODE`

若需要自动创建默认管理员，还必须配置：

- `DEFAULT_ADMIN_ENABLED=true`
- `DEFAULT_ADMIN_USERNAME`
- `DEFAULT_ADMIN_PASSWORD`
- `DEFAULT_ADMIN_EMAIL`

若不需要自动创建默认管理员，应显式设置：

- `DEFAULT_ADMIN_ENABLED=false`

## 3. 安全配置

- `JWT_SECRET` 长度不少于 32 字符
- 生产环境保持 `JWT_COOKIE_SECURE=true`
- 若部署在 HTTPS 下，确认 Cookie 的 `SameSite` 策略符合前端域名方案
- 若接入反向代理并希望按真实客户端 IP 做登录限流，必须：
  - 设置 `AUTH_TRUST_FORWARD_HEADERS=true`
  - 正确配置 `AUTH_TRUSTED_PROXIES`
- 若未配置可信代理，不应开启 `AUTH_TRUST_FORWARD_HEADERS`

## 4. 数据库与迁移

- 启动前确认 Flyway 迁移可正常执行
- 当前测试环境使用的是 MySQL 5.7，但运行时已有上游兼容性警告
- 正式环境建议使用 MySQL 8.0+

## 5. 业务初始化

- 至少存在一个可登录的 `ADMIN`
- 若要指派分组负责人，库中必须已存在角色为 `LEADER` 且状态为 `ACTIVE` 的用户
- 报名前应先配置：
  - 报名期
  - 方向树
- 分组前应先配置：
  - 选拔期
  - 分组数据

## 6. 当前功能核对

- 登录 / 注册 / 找回密码可用
- 公开方向接口仅返回启用方向
- 报名仅允许配置中的年级
- 管理员可维护方向、时期、分组、分组负责人
- 管理员和负责人可进行分组
- 管理员和负责人可拒绝申请
- 管理员和负责人可取消分组

## 7. 当前已验证的自动化结果

- `mvn.cmd -q -DskipTests compile` 通过
- `mvn.cmd test` 通过
- 当前测试总数：`78`

## 8. 已知非阻塞边界

- 当前负责人仍可看到所有未分组申请，不仅限于自己分组条件范围
- 当前系统只实现两层方向树
- 当前尚未实现自动分组、面试、任务提交、公告等后续模块
